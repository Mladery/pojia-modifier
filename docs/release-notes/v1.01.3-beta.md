# 破甲修改器 v1.01.3-beta

测试版。这一版只动「更新」这条路，不改注入逻辑。

## 更新提示以前为什么不弹

三处毛病叠在一起，任何一处都足以让提示永远不出现：

**一、只看 `/releases/latest`。** 这个接口会跳过所有预发布。于是 beta 版本发得再多，
它也只认正式版 —— 装 beta 的人永远收不到下一个 beta，界面上就一直「已是最新」。

**二、版本号只认两段。** `1.01.2` 被截成 `(1, 1)`，`1.0` 是 `(1, 0)`。两段版本碰两段
版本还看不出来，一旦第三段动了，比出来就是相等。

**三、界面解析不了后缀。** 刷出来的那行 `最新发布：1.01.2-beta` 里，正则只认数字和点，
`-beta` 一进来就断。

现在拉最近 30 个发布，在本地挑：版本最高的那一条，同版本号时稳的优先。

## 通道：三层，你选一层

后缀即通道，等级从低到高 `-alpha` < `-beta` < `-mod`（没有后缀就是正式版）。

收谁不收谁只看一条：**候选的等级不低于你自己的**。

| 你选的 | 会收到 |
|---|---|
| 前期测试通道（alpha） | alpha + beta + 正式 |
| 测试通道（beta） | beta + 正式 |
| 稳定通道（mod） | 只有正式 |

装的是哪个渠道，默认就收哪个渠道 —— 不用手动配。想换的话，界面左边现在是一条正经
导航栏：**一键破甲 / 运行记录 / 设置**，点「设置」进去，三个通道点一下就换，顺手还能
关掉「启动时检查更新」。写在程序自己的状态目录里（`state/_settings.json`），不碰注册表。

命令行等价：

```
pojia --settings                     # 看
pojia --settings "channel=mod"       # 换成稳定通道
pojia --settings "auto=off"          # 启动时不再查
```

## 顺便

`--check-update` 末尾会多打一行 `#update {...}`，界面读它，不再靠人看的字眼去猜。
文案怎么改都不影响判断。
