# 破甲修改器 v1.01-mod

作为 1.01 系列的首个稳定版本，本版本汇总了自 v1.01-beta 以来的主要用户相关变更。

## 新增功能

- 命令行改为带引导的菜单，回车重画、输错提示，命令结束后给出下一步建议。
- 不带参数启动直接进入图形界面，`--menu` 进入终端交互界面。
- 菜单顶部显示现场扫描的目标统计，选择目标时逐项标注已装、已生效与过期状态。
- 图形界面拆分为独立静态资源，左侧三页导航：一键破甲、运行记录、设置。
- 更新分三档通道（开发 / 测试 / 稳定），后缀即通道，按已安装渠道决定默认收取范围。
- 支持在界面与命令行（`--settings "channel=mod"`）之间切换通道，并可关闭启动时检查更新。
- `--check-update` 末尾输出机器可读的 `#update {...}`，界面据此判断版本与通道。
- 主界面新增结论条，显示成功、完成或失败；失败时摘出可定位的原文，并可跳转运行记录。
- 设置页新增「检查更新」，支持手动检查、就地安装，并显示下载进度与升级日志。
- 下载进度按已下载与总大小显示；服务端未提供长度时退化为已下载量。
- 安装程序识别已安装的旧版本，欢迎页、任务栏、进度页与完成页统一显示「升级」及升降版本号。
- 完成页新增默认勾选的「删除这个安装包」，仅删除程序自身发起升级所用的安装包。
- 界面内升级时程序自动退出、替换文件并重新启动，页面提示当前页面可以关闭。

## 体验优化

- 命令结束后的下一步提示仅在真实终端中出现，重定向到文件与界面面板中不输出。
- 中文表格按显示宽度对齐，全角字符按两格计算。
- 输出着色仅在标准输出为终端时启用，重定向、界面面板与 CI 中均为纯文本。
- 预演统一为逐文件报路径，并注明新增或重写；前缀随模式区分「预演」与「完成」。
- 预演汇总行改为「会改 N / 跳过 N / 失败 N」，不再表述为注入成功。
- 撤回同样按逐文件报路径，并区分预演与实际执行。
- 升级前清理上一版本遗留的下载文件，避免同名大文件堆积。
- 升级失败后保留安装按钮，可直接重试而无需重新检查。
- 成功与失败按退出码判定；只读动作（看现状、体检）即使提示需要处理也计为完成。
- 升级等待设有上限，进程 15 秒内未退出即强制结束并继续换装。

## 问题修复

- 修复 DSH 预设模式在打包版中始终失败的问题：块标量中的英文撇号被误判为引号，导致合规配置被判为不合格。
- 修复未选择任何目标时报错的问题，`all` 与 `*` 按全选处理。
- 修复更新提示不出现的问题：此前只读取正式版接口、版本号仅比较两段，且无法识别 `-beta` 等后缀。
- 修复点击安装新版后无响应的问题：等待进程退出的脚本没有上限，界面也不会自行退出。
- 修复通过安装程序安装的版本无法识别自身安装状态的问题，导致下载错误的包、附带目录失效、PATH 与卸载项不更新。
- 修复静默安装无条件删除安装包的问题，导致构建产物缺失。
- 修复全新安装后升级下载失败的问题：状态目录不存在时直接报错，已下载内容无法保存。
- 修复从终端启动时升级长时间卡住的问题：进程检测调用了同名的非系统程序，触发整盘遍历。
- 修复安装程序启动前的进程占用检查在部分环境下卡住的问题。

## 其他变更

- 版本号改为三段制，安装包版本资源统一归一为四段数字，带后缀不再导致编译失败。
- 发布流程按版本后缀自动标记预发布，稳定通道不再被提示升级到测试版。
- 发布产物上传改为幂等并带重试，多平台并行发布时不再因重复创建发布页而漏发文件。
- 界面进程通过环境变量告知核心仅在界面运行时输出下载进度行，命令行输出不受影响。
- 产物暂未附带代码签名，Windows 显示「未知发布者」，macOS 首次打开需经 Gatekeeper 确认。
