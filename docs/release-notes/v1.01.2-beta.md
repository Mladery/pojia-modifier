# 破甲修改器 v1.01.2-beta

测试版。这一版只修显示口径，不改注入逻辑。

## 预演现在一个口径

之前同一个「预演」，两种目标两种样子：

```
[完成] dsh          破甲模式将写入（desktop 将插入、web 将插入）      ← 只有一句，看不出动哪个文件
[预演] WorkBuddy Intl：会写 …\welcomemode\code\prompt.tpl            ← 逐个文件列出来
```

DSH 的 preset 模式走的是另一条写入路径，只回一句摘要，连 `[完成]` 这个前缀都不对 ——
预演根本没落盘，凭什么写「完成」。

现在统一：

```
[预演] DSH：会写 C:\Users\你\.dsh\profiles\desktop\cordis.patch.yml（desktop 新增）
[预演] DSH：会写 C:\Users\你\.dsh\profiles\web\cordis.patch.yml（web 新增）
  [预演] dsh          破甲模式将写入 2 个 profile（见上面逐个文件）

预演：会改 1 / 跳过 0 / 失败 0（一个字节都没动）
```

- 逐文件报路径，新增还是重写写在括号里；
- 每条前缀跟着模式走：预演是 `[预演]`，真打才 `[完成]`；
- 汇总行也不再冒充「注入成功」，预演就是「会改 N」；
- 撤回同理：`[预演] DSH：会从 … 删掉标记段`。

## 版本号

从这一版起用三段：`1.01.2-beta`。护照里存纯数字 `1.01.2`，对外显示带 `-beta`。

顺带修了 Windows 安装包的版本资源：`VIProductVersion` 只吃 `X.X.X.X` 四段数字，
以前是把版本号硬拼 `.0.0`，一旦版本号本身是三段或带后缀，makensis 直接编译失败。
现在由 `quad_version()` 归一（`1.01.2-beta` → `1.1.2.0`），去前导零、补足四段。
