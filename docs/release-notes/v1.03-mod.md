# 破甲修改器 v1.03-mod

作为 1.03 系列的首个稳定版本，本版本汇总了自 v1.03.1-beta 以来的主要用户相关变更。

## 新增功能

- 支持范围从 17 个目标扩到 20 个：新增 Reasonix、Trae CN、Qoder CN，国际版与国内版工具各打各的，可以并存。
- DSH 新增会话守卫（`--session-guard on|off`）：一轮结束后看一眼怎么收的，模型中途拒答、可重试的报错、一个字没吐出来，都替用户补一句「继续」。正常交付、用户自己按了停止、用户刚发过话一律不动。
- 会话守卫只用客户端公开的钩子，不跟用户抢方向盘；续跑每轮最多一次、每会话有上限，拒答另有熔断。
- 定位链补齐四个上一代有、这一代丢掉的来源：向内核要进程的镜像路径（不再只靠命令行）、桌面与开始菜单被 OneDrive 或组策略重定向时逐个问系统目录、卸载登记表四种写法全认、从 wb-switch / cc-switch 的配置里反查安装路径。
- 恢复分层特化注入：执行纪律、Claude、Kiro、Gemini、GLM 等层文本共享，多个目标叠同一份，改一处所有引用它的目标同时生效。
- Antigravity 拆成两个文件落盘，绕开单文件 24,000 字节封顶（超出是从尾部截断，自证段恰好在最后）。
- macOS 上补齐 `.app` 包识别：资源目录、模板、产品配置、安装候选各按包内路径取，DSH 在只有配置目录时也能接管。

## 体验优化

- 政策改为就地替换模板里的原生政策段，不再往文末追加第二份。单个模板从 46.9K 字降到 37.5K 字，客户端每轮少带一份政策。
- 没有政策段的短提醒模板不再注入——往里塞整份政策只会冲掉它原本的语义，`--status` 里单独标注跳过。
- 注入前先摘掉更早版本留下的块，同一个文件不会两版叠加；重复执行 `--apply` 判定为「已是最新」，不重复写盘。
- 云记忆内容一致时跳过重写，不再每次清只读锁重跑一遍；写完置只读，防止客户端把过期档案回写成空记忆。
- **撤回只剪自己那块。** 注释块形态的注入按标记精确裁剪，不再把文件搬回几天前的快照——同一份 `cordis.patch.yml` 里有用户自己的 preset、别家安装器写的段，一条 `--revert` 不会再把它们一起抹掉。整文件替换、字段改写这类重建不出原样的，仍然走干净备份。
- `--status` 的目标数只统计真正该注入的文件。
- 自更新的等待改成零管道：固定等几秒、无条件结束旧进程、再换装，不再轮询进程。

## 问题修复

- 修复「破甲自检」回复上一代口令的问题：客户端模板里留着更早分支的自证说明，不在本工具标记范围内，历次注入只替换自己那一块；同时账号级云记忆有两份正文，此前只改副本。现在注入前清掉块外旧段，两处正文一起替换并保持逐字一致。
- 修复注入写进了模板、客户端真正读的那份没改的问题：落点改到客户端实际加载的 `cli/product.json`，模板只作为出厂默认值。
- 修复 `product.json` 里堆叠十几份旧自证段的问题，一次清成一份。
- 修复测试版收不到同系列稳定版的问题：稳定版序号比上游测试版小（`1.03` 低于 `1.03.9`），只按数字比较会被判成更旧。现在同一系列里稳定版恒为新，两个方向都成立，跨系列比较保持原样。
- 修复 Trae CN 升到 1.107 之后写不进去的问题：全局规则不再读 `~/.trae-cn/rules/project_rules.md`，只认 `user_rules.md` 与 `user_rules/**.md`。落点改到 `~/.trae-cn/user_rules/pojia.md`，定位标记改用常驻的 `argv.json`，进程反推重写（安装根与配置根不在一条祖先链上）。
- 修复自更新卡在命令行窗口的问题，两层：安装器调用显示方式的参数错位，本该隐藏的删除批处理弹成黑窗；换装批处理由无 console 的方式拉起，`tasklist | findstr` 的管道写端被系统配的 console 宿主按着不放，findstr 永远等不到结束——结束那个窗口等于松开句柄，安装才继续。现在整条换装链没有管道，进程改用隐藏 console 的方式拉起。
- 修复界面在升级后不肯退场的问题：退场判定原来只看最后二十行输出，下载进度一多就把关键行挤出去了。
- 修复第二落点撤回后留下空壳的问题，技能包整份删除；技能文件的 YAML 头不再被 agent 头覆盖。
- 修复 WorkBuddy 国际版串到国内版的问题，按 `WorkBuddyAI.exe` 与包名分开认。
- 修复 macOS 上除 zcode、codex 外全部显示「未安装」的问题：默认位置也套了「必须命中标志物」的强判据，而这些目录里常年没有标志物；另有 Reasonix、DSH、WorkBuddy 三条路径是 Windows 形态。现在默认位置只要求「目录存在且非空」，兜底候选仍要求含标志物，空目录依旧不认。

## 其他变更

- 版本号记为 `1.03-mod`。
- 感谢 [@zixuan203344](https://github.com/zixuan203344) 贡献 Reasonix、Trae CN、Qoder CN 三个目标的适配，目标数 17 → 20。
- 解析器不再把 `bin`、`resources`、`Program Files` 这类通用目录名当成安装根；盘符根收手。
- 产物暂未附带代码签名，Windows 显示「未知发布者」，macOS 首次打开需经 Gatekeeper 确认。
- macOS 的 `.app` 适配为只读识别与路径拼接，未在真机验证；识别层有测试覆盖，若仍有目标认不出，把 `--status` 的输出提到 issue。
