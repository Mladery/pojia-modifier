# 破甲修改器 v1.01.8-beta

测试版。这一版只修一件事：**刚装好就点升级，下载完存不下来**。

## 报错长这样

```
当前：1.01.6-beta　收：测试通道
最新发布：1.01.7-beta（测试通道）
[失败] 落盘失败：[Errno 2] No such file or directory:
       'C:\Users\...\Programs\pojia-modifier\state\_update_pojia-modifier-windows-x64-setup.exe.part'
```

12 MB 下完了，最后一步写盘失败 —— 白下一次。

## 为什么

`state/` 是程序**跑过 apply 之后**才建出来的目录（护照、快照、备份记录都放那儿）。
用 setup 新装的机器上，它还不存在；而升级恰恰是第一件要往那儿写东西的事。

下载的落盘逻辑是「先写 `.part`，校验通过再改名」，写之前没人检查父目录在不在，
于是 `open()` 直接 ENOENT。跟网络、跟权限、跟磁盘满都没关系 —— 缺的就是一个目录。

## 现在

落盘前先把父目录建出来（`os.makedirs(..., exist_ok=True)`），只在真需要时建，
不会动 `state/` 里已有的东西。加了两个回归测试：一个在空目录里下载必须成功，
另一个确认建目录不会抹掉原有文件。

## 已经在 1.01.6 / 1.01.7 上的人

这一次得手动补一下，因为**执行下载的是那个有毛病的旧版本自己**，它修不了自己。
建一次目录就行，之后每次升级都会自己维护：

```
mkdir "%LOCALAPPDATA%\Programs\pojia-modifier\state"
```

然后再点「安装」。
