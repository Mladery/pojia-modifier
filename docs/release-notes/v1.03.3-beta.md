# v1.03.3-beta

测试版。政策注入换了落点，同时新增三个目标，支持范围 17 → 20。

## 问题修复

- 注入改为写客户端真正加载的 `cli/product.json`，不再只改模板 —— 之前模板改了、
  客户端没读，等于没破。
- 「破甲自检」回复里的版本号与仓库地址恢复为当前版本。
- `product.json` 里堆叠 12 份的旧自证段清成一份。
- 第二落点撤回后残留的问题修掉：技能包整份删除，不留空壳。
- 技能文件的 YAML 头不再被 agent 头覆盖。
- 注入前先摘掉更早版本留下的块，同一个文件不会两版叠加。

## 体验优化

- 政策改为就地替换模板里原生的政策段，不再往文末追加第二份。
  单个模板从 46.9K 字降到 37.5K 字。
- 没有政策段的短提醒模板不再注入。
- 重复执行 `--apply` 判定为「已是最新」，不重复写盘。
- 云记忆内容一致时跳过重写；写完后置只读。

## 新增目标

### Reasonix

配置根在 `%APPDATA%\reasonix`（不是 `~/.reasonix`，那里只有运行时锁目录），
落点 `AGENTS.md`。不改客户端自己的系统提示文件，避免顶掉用户写的内容。

### Trae CN

配置根 `~/.trae-cn`，落点 `rules/project_rules.md`。国际版仍在 `~/.trae`，
两者可以并存，各打各的。

### Qoder CN

配置根 `~/.qoder-cn`，写 `agents/purge/qodercn.md` 与 `skills/purge/SKILL.md`
两处；撤回时技能包整份删除。
