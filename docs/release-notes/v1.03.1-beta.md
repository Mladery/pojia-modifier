# 破甲修改器 v1.03.1-beta

测试版。这一版处理两件事：口令回的还是上一代，以及测试版收不到同系列稳定版。

## 问题修复

- 修复发「破甲自检」回来的是上一代口令的问题：回复里的版本号与仓库地址停在更早的社区版，与当前这份对不上。
- 原因一：客户端模板里留着更早一个分支写下的自证说明，它不在本工具自己的标记范围内，历次注入只替换自己那一块，旧的部分一直没被清掉。
- 原因二：账号级云记忆档案里有两份正文，段落里那份是副本，尾部 JSON 里的 `memoryBlock` 才是客户端每轮读取的那份；此前只改副本，客户端照样拿旧的。
- 现在注入前清掉标记范围之外的旧自证说明，两处正文一起替换，保持逐字一致。
- 修好之后重新应用一次即可，不需要手工改文件。
- 修复测试版收不到同一系列稳定版的问题：装着 `1.02.1-beta` 时，`1.02-mod` 发布后没有任何升级提示。
- 原因：稳定版的序号比它的上游测试版小（`1.02` 低于 `1.02.1`），只按数字比较会被判成更旧。
- 同一系列里稳定版恒为新，两个方向都成立：稳定版不会被同系列测试版反推，测试版也能正常收到同系列稳定版。
- 检查更新改为挑「该装的」那一个，而不是序号最大的那一个；否则测试版的候选永远是它自己，稳定版发了也看不到提示。
- 跨系列的版本比较保持原样，新线路的测试版照常提示。

## 说明

- 稳定通道本来就不收测试版；同系列规则只影响把通道设成「测试」又装了稳定版的情况。
- 云记忆档案在写入前会备份；档案缺失原始备份时只告警，不拿注入版当原档。
- 新增用例覆盖：块外旧自证段的清理、已是最新状态下的重写、云记忆两处正文同步、参数字段保留、JSON 损坏时不改写、候选发布的挑选。
