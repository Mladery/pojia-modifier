# 破甲修改器 v1.01.4-beta

测试版。这一版只动 Windows 安装包，程序本体没有变化 —— 从 1.01.3 升上来，
文件是同一个，变的只是「装」和「升级」这条路的手感。

## 已装过的人，看到的第一页写的是「升级」

以前不管你装没装过，双击 setup 都是同一张脸：「欢迎使用 破甲修改器 安装程序」
「在安装之前，请先关闭其他所有应用程序」。可对已经装过的人来说，他做的不是安装，
是换掉一个已有的版本 —— 这句话是错的，还容易让人以为要装出第二份。

现在开头先认人：注册表里有 InstallDir、或者程序目录里 exe 还在，就算「已装」。
认到之后，这一页自己的字换掉：

- 标题：**欢迎使用 破甲修改器 升级程序**
- 正文：已检测到 1.01.3，将就地升级到 1.01.4-beta。备份、状态和你的设置都留在原处。
  升级前请先关闭正在运行的 破甲修改器，否则文件会被占用。
- 任务栏：破甲修改器 升级
- 进度页抬头：正在升级 破甲修改器 / 覆盖旧版文件，备份和设置都保留
- 完成页：升级完成

改的是这一页的字，不是再加一个窗口：向导前面不弹任何确认框，双击 setup 之后
第一个能点的东西还是那个「下一步」。页面本身、按钮位置、走法都没变。

判定不只看注册表：卸载程序被强删、注册表被清理工具扫掉，但程序目录里的 exe 还在，
照样认得出来 —— 否则会在旁边再摊一份，PATH 和卸载项指哪个都说不清。

没装过的人看到的还是原来那套：欢迎页、免责声明、组件、装到哪儿，一页不少。

## 装完把安装包删掉

完成页多了个复选框，**默认勾上**：

> ☑ 删除这个安装包（已经装好了，留着占地方）

不删的话，每个版本都在下载目录里留一个几十兆的同名文件，攒几次就分不清哪个是哪个。

删的是「正在运行的自己」。Windows 不给删已加载的 exe，所以交给一个守在旁边的批处理：
它等两秒、等安装程序退出再动手，删不掉就再等（杀毒软件刚扫完那几十秒会锁文件），
最多试三十次；最后把自己也删掉，临时目录里不留东西。

这个删除只发生在程序自己发起的那次升级里（安装程序带 `/POJIA_SELFDEL`）。
你手动敲 `setup.exe /S` 装到别处、或者批量部署脚本里跑一次，安装包不会被吃掉。

## 界面上点「安装新版」，剩下的不用你管

以前在界面里点升级，程序下完包会说「关掉这个窗口」，然后等你手动关 —— 而只要你
不关，它还占着要替换的那个 exe，批处理就一直等下去，看上去就是「点了没反应」。

现在：

1. 点一下就开始，页面盖一层「正在升级…这个页面可以关掉了」；
2. 程序自己退出（1.5 秒后），批处理接手；
3. 主进程要是 15 秒还没退干净，`taskkill /f` 直接结束它，不再无限等；
4. 换装完自己重新打开，新版本又是一个新窗口。

状态目录里上一版留下的 `_update_*.exe` 顺手清掉 —— 那玩意儿一个几十兆。

`--update` 的静默升级走同一条路 —— 那条路没有完成页，也就没有人可问，
临时目录里的 setup.exe 直接清掉。
