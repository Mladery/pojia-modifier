# 破甲修改器 v1.01.5-beta

测试版。这一版只动界面上的「结果」这件事：跑完到底成没成，不用再翻日志猜。

## 主界面上多一条结论

上一版把运行输出整个搬到了「运行记录」页 —— 好处是主界面干净了，坏处是点完
「一键破甲」，人被带到日志页，看完几百行还得自己判断：这算成功还是失败？

现在两步：

1. 点下去照旧切到「运行记录」，输出实时往下滚（这页不动）；
2. 跑完自动回到主界面，按钮下面出现一条结论：

> ● **成功**　一键破甲完成，用时 6.4s。每一步都记在运行记录里。 　[看运行记录]

没跑通就是朱红的一条：

> ● **失败**　一键破甲没有跑通：目标目录不存在。报错请看运行记录。 　[看运行记录]

失败那句会把输出里第一行能认出毛病的原文摘出来（`[!]` / `[x]` / Traceback /
失败 / 错误： / 拒绝访问 这些），太长的截到 70 字，够定位就行。想看全文点右边。

**成败看退出码，不看字样。** 一开始是按输出里有没有「失败」判的，结果体检一跑：
「体检结果：5 项需要处理」，满屏 `[fail]`，其实它干完活了 —— 按字样判就会把
一次正常的体检标成失败。现在接口在流末尾补一行退出码（0 跑通 / 1 有没办成的 /
2 根本没跑起来），界面按它分三档：

| | 结论条 |
|---|---|
| 0 | ● **成功** 一键破甲完成，用时 6.4s |
| 1（改文件的动作） | ● **失败** 没有跑通：… |
| 1（只读动作，如体检） | ● **完成** 跑完了，有需要处理的地方 |
| 2 | ● **失败** 没有跑通：… |

结论条只留在主界面：换到别的页再回来还在，开始下一次动作时清掉 —— 免得拿上一次
的结果糊弄这一次。
