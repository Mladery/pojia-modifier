# 破甲修改器 v1.02-mod

本次为紧急修复版本，处理上一版暴露出的两个问题。

## 问题修复

- 修复升级后「破甲自检」仍回复上一代口令的问题：回复里的版本号与仓库地址停在更早的社区版，与当前这份对不上。
- 原因：客户端模板里留着更早一个分支写下的自证说明，它不在本工具自己的标记范围内，历次注入只替换自己那一块，旧的部分一直没被清掉；两份同时存在时，可能命中旧的那条。
- 现在注入前先清掉标记范围之外的旧自证说明，只保留当前这一份。
- 已经装过老版本的机器，重新应用一次即可清干净，不需要手工改文件。
- 修复测试版收不到同一系列稳定版的问题：装着 `1.02.1-beta` 时，`1.02-mod` 发布后没有任何升级提示。
- 原因：稳定版的序号比它的上游测试版小（`1.02` 低于 `1.02.1`），只按数字比较会被判成更旧。
- 现在同一系列里稳定版恒为新，两个方向都成立：稳定版不会被同系列测试版反推，测试版也能正常收到同系列稳定版。
- 跨系列的版本比较保持原样，新线路的测试版照常提示。

## 其他变更

- 版本号记为 `1.02-mod`。
