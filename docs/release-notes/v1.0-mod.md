# 破甲修改器 v1.0-mod

第一个公开发布版本。产物名 `pojia-modifier`。

## 它做什么

把你电脑上 17 个 AI 客户端「自己改不到的内置提示词」，换成你自己写的那一份。

- **一份人格文本，17 个客户端通用** —— 不用各改各的。
- **只做文本文件层面的替换** —— 不修改客户端本体，不删包、不写注册表、不装服务。破甲流程全程离线。
- **改前先备份** —— 每个目标首次改动都写旁路备份；`--revert` 一键回原版。
- **当场能自证** —— 客户端新会话里发一句 `破甲自检`，回一行就说明真载入了，不靠「感觉生效了」。

支持的目标：`dsh` `wb` `wbintl` `zcode` `codex` `cursor` `claude` `antigravity` `qwen` `iflow` `trae` `codebuddy` `opencode` `windsurf` `cline` `copilot` `kiro`。

## 下载哪个

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows x64 | `pojia-modifier-windows-x64-setup.exe` | 安装版，**推荐**。装到 `%LOCALAPPDATA%\Programs\pojia-modifier`，建开始菜单项与卸载项，全程不要 UAC |
| Windows x64 | `pojia-modifier-windows-x64.exe` | 便携单文件。双击即跑、什么都不装；每次启动自解包到 `%TEMP%`，个别安全软件会拦临时目录里的可执行文件 |
| Linux x64 | `pojia-modifier-linux-x64-installer.run` | 装到 `~/.local/share/pojia-modifier`，软链到 `~/.local/bin`，带桌面项与 `--uninstall` |
| Linux x64 | `pojia-modifier-linux-x64` | 直接 `chmod +x` 后运行 |
| macOS Intel | `pojia-modifier-macos-x64-installer.command` | 双击安装，同上装到 `~/.local/share/pojia-modifier` |
| macOS Apple Silicon | `pojia-modifier-macos-arm64-installer.command` | 同上 |
| 三平台 | `pojia-modifier-<平台>` | 不装，直接跑 |

`SHA256SUMS.txt` 与所有产物发在同一条 Release 里，下载后可对照。

**本次产物没有代码签名。** Windows 属性页会显示「未知发布者」，SmartScreen 可能提示一次；macOS 两个包未签名也未公证，从浏览器下载后首次双击会被 Gatekeeper 拦住 —— 右键「打开」，或 `xattr -d com.apple.quarantine <文件>` 之后正常双击。介意的请用源码运行。

## 装上先跑这三条

```bash
pojia-modifier --version              # 看得出是 pojia-modifier 就对了
pojia-modifier --status               # 只读：17 个目标各是什么状态
pojia-modifier --dry-run --apply      # 预演：只报要改哪些文件，一个字节都不写
```

确认没问题再去掉 `--dry-run`。不带任何参数启动 = 直接开图形界面（本机 `127.0.0.1` + 随机 token 的网页 UI，关掉窗口即退出）。
