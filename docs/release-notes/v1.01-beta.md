# 破甲修改器 v1.01-beta

测试版。命令行这一版重做了：带引导，不再是六十个开关糊一屏。

## 命令行现在长这样

不带参数双击 = 图形界面。想用命令行，`--menu` 进来：

```
  破甲修改器 1.01-beta   把客户端的内置提示词换成你自己那份
  17 个目标：已装 12 · 已生效 0
──────────────────────────────────────────────────────────────────
  [1] 看现状   只读：每个目标装没装、注没注
  [2] 预演     只报会改哪些文件，一个字节都不写
  [3] 破甲     真改，改前自动旁路备份
  [4] 还原     变回原版，备份留着
  [5] 体检     磁盘 / 凭证 / 自证就绪，只读
  [6] 快照     存一份基准，之后能跟它比
  [7] 对比     跟上次基准比，看哪变了
  [8] 守护     后台守卫任务：安装 / 卸载 / 查看
  [9] 清理     撤回全部并删除状态目录
  [0] 退出
──────────────────────────────────────────────────────────────────
  选 1-9；回车重画，0 退出
```

顶部那行是**现场扫出来的**：装了几个、几个真生效，不是写死的文案。选目标时每一步都带状态灯 —— 灰=没装，绿=当前，黄=过期，红=异常。

几个细节：

- **回车不退出**。菜单里空输入只重画，输错给一句「没有这一项」再回到菜单。以前空输入直接结束进程，按两次回车菜单就没了。
- **命令跑完给下一步**。`--status` 之后提示去预演，`--apply` 之后提示去发自证口令，`--revert` 之后提示还能 `--purge`。只在真终端里出现，管道和界面面板不会多这些行。
- **中文对齐**。表头按显示宽度算，全角字符算两格，中英混排不会歪。
- **上色只看一条**：stdout 是不是真终端。重定向到文件、被界面面板读、进 CI —— 一律纯文本，不夹带转义码。

## 修掉的两个硬伤

**① DSH 的 preset 模式在打包版里必失败。**
报错是「生成的内容 YAML 解析不过（括号/引号没配平），已跳过这一份」。起因是兜底检查器把 `prefix: |` 块标量里的英文撇号当成了引号开头（`user's`、`don't`），一路开到文件尾，于是合规的文件被判红。打包版没有 PyYAML，走的就是这条兜底路径，所以源码态一直正常、装好的 exe 一直失败。现在块标量、`!!js` 表达式、整行注释都不参与配平计数。

**② 一个目标都不勾就报错。**
界面在没勾任何目标时传 `--target all`，核心把它当未知目标。`all` / `*` 现在按全选处理。
