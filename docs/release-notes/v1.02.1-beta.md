# 破甲修改器 v1.02.1-beta

测试版。这一版修的是稳定版用户被劝「升级」回自己那份测试版。

## 问题修复

- 修复装了 1.01-mod 之后，界面顶部仍提示「有新版本 v1.01.9-beta 可以装（当前 v1.01-mod）」的问题。1.01-mod 由 1.01.9-beta 切出，内容一致而序号更小（1.01 < 1.01.9），只按数字比较会把上游当成新版。
- 同一系列（前两段版本号相同）内，稳定版不再收到 alpha 与 beta 的提示；跨系列照常比较，新的版本线仍会提示。
- 命令行 `--check-update` 与界面顶部提示共用同一条规则，两处不会再给出互相矛盾的结论。

## 现在的判定

| 当前 | 候选 | 是否提示 |
|---|---|---|
| 1.01-mod | 1.01.9-beta | 否，同系列，稳定版已经包含它 |
| 1.01-mod | 1.02.1-beta | 是，跨系列 |
| 1.01.8-beta | 1.01.9-beta | 是 |
| 1.01.9-beta | 1.01-mod | 否，不做降级 |

## 说明

- 稳定通道本来就不收测试版；这条规则只影响把通道设成「测试」又装了稳定版的情况。
- 已经停在 1.01.9-beta 的用户切到稳定通道不会降级到 1.01-mod，两者内容相同，等下一条稳定线发布再切。
- 判定函数新增 8 条用例覆盖上述组合，含同系列不推与跨系列照推两侧。
